# LearnFlow — Online Course Management System

> **Learn. Track. Complete.**

LearnFlow is a modern **Online Course Management System** designed to provide a structured, engaging, and responsive learning experience for students while giving administrators a centralized platform for managing courses, learners, and learning content.

🌐 **Live Demo:** https://learnflow-management-system-topaz.vercel.app/

💻 **GitHub Repository:** https://github.com/Ansh-vibe/cognevance-lf-management-system

---

## 📌 Project Overview

**LearnFlow** is a full-stack-oriented EdTech platform concept focused on simplifying online learning and course management.

The platform provides an intuitive interface for discovering learning paths, exploring courses, tracking learning progress, and managing educational content.

The project was developed as a practical full-stack web application project demonstrating modern web development concepts including:

* Responsive frontend development
* Component-based architecture
* Course discovery
* Learning paths
* Student experience
* Admin management
* Progress-oriented UX
* Modern SaaS interface design
* Production deployment with Vercel

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* pnpm
* Git

---

### 1. Clone the repository

```bash
git clone https://github.com/Ansh-vibe/cognevance-lf-management-system.git
```

---

### 2. Navigate to the project

```bash
cd cognevance-lf-management-system
```

---

### 3. Install dependencies

```bash
pnpm install
```

---

### 4. Start the development server

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```

---

## 🏭 Production Build

Create an optimized production build:

```bash
pnpm build
```

Start the production server:

```bash
pnpm start
```
